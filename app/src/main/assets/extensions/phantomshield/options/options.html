Cómo funciona la privacidad y límites

El bloqueo local funciona sin IA. Las listas se descargan desde EasyList, Adblock Plus y GitHub: esos servidores ven tu conexión y las solicitudes de descarga, pero no reciben tu historial.

Puedes usar un proveedor compatible con OpenAI Chat Completions, Claude Messages u OpenRouter para clasificar los posibles anuncios que las reglas locales no reconocen. Es opcional, puede tener coste y no garantiza detectar todos los anuncios. Los anuncios de video de YouTube se eliminan con reglas locales, sin IA.

La clave se guarda en el perfil local, sin cifrado adicional, y solo se envía a la API configurada. La IA no se utiliza en ventanas privadas.
