PhantomShield: privacidad e IA

El bloqueo local funciona sin IA. La extensión descarga listas de filtros desde EasyList y GitHub; esos servidores ven tu dirección de conexión y las solicitudes de descarga. No se les envía tu historial de navegación. Información de privacidad y limitaciones.

Puedes añadir un proveedor compatible con Chat Completions para clasificar señales de posibles anuncios. Es opcional, puede tener coste y no garantiza detectar todos los anuncios. Aceptar permite enviar los datos indicados abajo; rechazar mantiene el bloqueo local.

Se añade /chat/completions si la URL no termina así. Solo HTTPS.

La clave se guarda localmente en el perfil del navegador y solo se envía a la API configurada. Para distribuir tu app, usa credenciales de usuario o un backend; no incluyas una clave compartida en la extensión.

Nombres de host exactos. Autorizar ejemplo.com no autoriza sus subdominios. Ningún sitio está autorizado al instalar.

El proveedor recibe también la clave configurada y la conexión de red. La IA puede equivocarse y consumir cuota. Se limita a 12 candidatos por lote y tres lotes por página; las ventanas privadas quedan excluidas. Puedes desactivarla o pausar un sitio para restaurar lo ocultado por IA.
